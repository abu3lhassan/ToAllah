# درب الزهراء للختمات - نسخة ويب v0.6

هذه نسخة مراجعة ويب مستقلة تعمل بفتح ملف `public/index.html` مباشرة من المتصفح.

## أهم ما في v0.6

- اعتماد النسخة v0.4 كأساس بدون تغيير المنطق العام.
- تحويل تاريخ الختمة إلى اختيار من التقويم الميلادي.
- توليد اليوم والتاريخ الهجري والتاريخ الميلادي تلقائيًا من التاريخ المختار.
- استبدال نوافذ المتصفح الافتراضية بنوافذ داخلية مصممة للموقع.
- تحسين تجربة حجز الجزء وإدخال اسم المشارك.
- تحسين نوافذ تأكيد الإنجاز والحذف وإدخال رمز الإدارة.
- الحفاظ على التصميم البريميوم والدعم للجوال والتابلت والكمبيوتر.
- إبقاء حاسبة زكاة الفطرة بنفس منطق الحاسبة الأصلية.

## طريقة الفحص

افتح الملف:

```text
public/index.html
```

## ملاحظات

- هذه النسخة ما زالت تحفظ البيانات داخل المتصفح فقط.
- بعد اعتمادها يتم نقل المنطق إلى Cloudflare Worker + D1.
- رمز الإدارة مؤقت للنسخة الحالية، وسيتم تحويله لاحقًا إلى تحقق من قاعدة البيانات.
